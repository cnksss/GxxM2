### 1.2 通信拓扑

```
Client ──► LoginGate ──► LoginSrv            (账号登录，CM_2000 系列协议)
       ──► SelGate    ──► DBServer           (角色创建/选择，CM_100 系列协议)
       ──► RunGate    ──► M2Server           (游戏玩法，CM_3xxx 系列协议)
                        M2Server ◄──► DBServer (角色存取，TSockData)
                        各程序 ◄──► LogDataServer (日志)
       GameCenter ◄──管理──► 全部服务端进程
```

- 网关协议帧：`TDefaultMessage`（Recog:Int64 + Ident/Param/Tag/Series:Word）经 **6-Bit 编码**（`EDcode`）后封装；网关间使用 `RUNGATECODE = $AA55AA55` 魔数头。
- 文本编码：**GBK (CP936)**，全部协议字符串按 ANSI 字节处理。
- 压缩：zLib（Delphi `ZlibEx` → C# `System.IO.Compression.ZLibStream` / Ionic 兼容 raw deflate）。

### 2.2 关键技术决策

| 领域 | Delphi 现状 | C# 方案 | 保真策略 |
|---|---|---|---|
| 运行时 | Delphi 7 RTL | .NET 8 + `System.Data.SQLite` + `MySqlConnector` | RTL 语义经 `DelphiRTL` 垫片 1:1 复刻 |
| UI 框架 | VCL (TForm) | WinForms (`System.Windows.Forms`)，net8.0-windows | 窗体/控件/事件逐一对应；DFM 布局 → 设计器代码 |
| 网关网络层 | WinSock2 + IOCP（自研 IOCPManager/SHSocket） | `System.Net.Sockets.Socket` + `SocketAsyncEventArgs`（底层即 IOCP） | 逐函数对应：AcceptEx/收发缓冲/发送队列/节流规则 |
| 服务器间连接 | TClientSocket/TServerSocket (ScktComp) | 同上 Socket 封装 `TFDSocket` 轻量包装 | 阻塞语义对齐 |
| 文本编码 | AnsiString (GBK) | `string` + `Encoding.GetEncoding(936)` 显式字节转换 | 协议层一律 byte[]，显示层 UTF-16 |
| packed record | `packed record` | `[StructLayout(LayoutKind.Sequential, Pack=1)] struct` + `Marshal.SizeOf` + `BytesOf/FromBytes` | 二进制布局与 wire-format 完全一致 |
| zLib | ZlibEx (zlib 1.2x) | `ZLibStream`/`DeflateStream`（对齐 ZlibEx 的 raw-deflate 封装） | 压缩往返测试 |
| 加密 | 自研 DES/AES/RSA/MD5/CRC | System.Security.Cryptography + 逐行移植的自研变体（DesNew2/EncryptUnit_LF 等私有算法必须手写移植） | 黄金向量测试 |
| 线程 | TThread/TCriticalSection | `Thread` / `lock` / `ConcurrentQueue` | 保持原线程模型（主循环 + 消息队列） |
| INI | TIniFile + 自研 FastIniFile | 移植 FastIniFile（内存缓存 + 磁盘同步） | 解析行为测试 |
| 数据库 | ASqlite3 + MySQL Direct | `System.Data.SQLite` + `MySqlConnector`；建表 SQL 逐字保留 | 表结构 SQL 原样执行测试 |
| 脚本 | NPC 脚本解释器（HandleNpcCmds 等） | 逐行移植解释器（非 Lua，M2 自有脚本引擎） | 脚本用例测试 |
| 客户端渲染 | HGE 1.81（DirectX 8） | `IHge` 抽象接口 + GDI+ 双缓冲实现（Silk.NET/OpenGL 后端可插拔） | 接口面 1:1：Texture/Sprite/Font/Transform |
| 客户端音频 | Bass 2.4 | Bass.Net P/Invoke 同一 bass.dll | 同一 native 库 |
| 反调试/VMP/VEH | VMProtect/VEH/内联汇编 | 设计为 `IAntiCheat` 空实现 + 保留协议兼容字段（托管运行时无意义且不可移植） | 协议字节兼容 |

### 2.3 不移植项（并说明理由 → 详见 §10 审计清单）

以下属 Windows 原生防护/混淆，与业务逻辑无关，托管运行时不存在对应语义，按协议兼容原则保留空实现或去除：

1. VMProtect SDK 调用（VMProtectSDK.pas 及各 `.inc`）→ `VmpSdk.Stub`。
2. VEH 向量化异常/内联反调试汇编（Client.dpr、CheckProcessModules、BeaEngine 反汇编器）→ 托管异常处理替代。
3. FastMM 内存泄漏检测（调试器功能）→ .NET GC 替代。
4. IOCP 句柄级 hack（GetTickCount 钩子等）→ 语义等效的标准实现。

## 3. 类型与语义映射规则（编码规范）

### 3.1 基础类型

| Delphi | C# | 说明 |
|---|---|---|
| Integer/LongInt | `int` | |
| Cardinal/LongWord/DWORD | `uint` | 与 API 交互处保留 uint |
| Word/SmallInt/Byte/ShortInt/Boolean | `ushort`/`short`/`byte`/`sbyte`/`bool` | |
| Int64 | `long` | TDefaultMessage.Recog 已是 64 位 |
| AnsiString | `string`（协议层：`byte[]` + GBK） | `EncodingUtil.GBK` 统一 |
| PAnsiChar/PByte/指针 | `byte[]` + `offset` 参数 或 `unsafe`/`Span<byte>` | 消除指针语法但保字节语义 |
| TDateTime | `DateTime` + `DelphiRTL.DelphiDate`（双精度天数换算） | 原格式 `StrToDate` 兼容 |
| TList/TObjectList | `List<T>` | |
| TStringList | `GXX.Core.TStringList`（保序 + Name=Value 语义 + SaveTo/LoadFrom GBK） | |
| set of TEnum | `[Flags] enum` | |
| record（非 packed） | `struct`（默认布局） | |
| packed record | `[StructLayout(Pack=1)] struct` + 序列化助手 | wire 格式不变 |
| array[0..N] of T | `T[N+1]` 固定数组 | |
| string[N]（短字符串） | `ShortString(N)` 结构（长度字节 + GBK 字节） | 逐字节兼容 |
| class 引用语义 | `class` | Delphi 对象皆引用 |
| procedure of object | `delegate`/`Action`/`EventHandler` | |
| property | `property` | |
| unit initialization | 静态构造器 / `ModuleInitializer` | |

### 3.2 RTL 函数映射（`GXX.Core.Rtl.DelphiRTL`）

`Copy/Pos/Delete/Insert/IntToStr/StrToInt(Def)/Trim/UpperCase/LowerCase/Format/FormatDateTime/Inc(天)/Trunc/Frac/Now/GetTickCount/MaxInt…` 全部以扩展方法或静态函数提供，语义对齐 Delphi（含边界行为：Copy 越界返回空串、Pos 1-based、StrToInt 失败抛异常而 StrToIntDef 返回默认）。

### 3.3 命名规则

- 文件名与原 .pas 单元名一致（`ObjBase.pas` → `ObjBase.cs`），便于对照审计。
- 类型名保留 `T` 前缀（`TDefaultMessage`），常量名原样（`CM_WALK`、`RUNGATECODE`）。
- 全局变量（Delphi unit-level var）→ 对应 `public static class XxxGlobal { public static ... }`。
- VCL 窗体：`TfrmMain` → `FrmMain : Form`，事件绑定在设计器对应方法中保留原名（`FormCreate` → `FrmMain_Load`，内部代码逐行对应）。

### 3.4 并发与消息泵

- 服务端主循环（TfrmMain.Timer / 线程 while+Sleep）→ `Thread` + `Stopwatch.GetTimestamp()` 计时，`GetTickCount` 语义由 `Environment.TickCount` 封装（uint 回绕）。
- `Synchronize` → `Control.BeginInvoke`。
- 自定义消息 PostMessage（GameCenter↔M2）→ `ConcurrentQueue<Command>`。

## 7. 风险与对策

- **GBK 代码页**：.NET Core 需 `Encoding.RegisterProvider(CodePagesEncodingProvider.Instance)`（Directory.Build.props 引入 `System.Text.Encoding.CodePages`）。
- **变长 packed record**（含 string[N]）：统一 `ShortString` 结构 + `BytesOf/FromBytes` 助手，测试锁布局。
- **Delphi 1-based 字符串**：转换期以 0-based 重写边界，测试覆盖 Copy/Pos 语义。
- **ObjBase 巨类**：拆分 partial class 文件但保留单一类型 `TCreature`，方法名原样。
- **UI 窗体量大**（M2 40+、Client 20+、其余 30+）：逐窗体转换，布局以 `ToString` 值对齐 DFM 属性；不影响协议正确性的装饰性属性允许简化但控件与行为保留。
