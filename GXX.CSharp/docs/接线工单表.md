# 接线工单表（GXX：Delphi7 → C# 全量翻译工程）

> **本表是什么**：把全工程的**接缝（seam / 注入点）**汇成一张**可执行工单**——每行回答
> 「谁赋值、谁读、默认是什么、**忘记注入会发生什么**、现在接了没有、卡在哪」。
>
> **为什么需要它**：台账 **§58.5** 的战略裁定 ——
> *"多条车道独立报告『一条接缝都没真正接宿主（全部默认「无宿主」）⇒ **无端到端行为被验证**』；
> `MAPPED` 定义维持『有移植证据』不变，但**目标的可验证部分现在主要卡在『接线 + 端到端』**"*。
> 本表就是那次裁定要求的「**把各车道的接缝清单汇总成一张接线工单表**」。
>
> **出处**：车道 `p17-m2-hostwire`。
> **口径来源**：台账 §33.4（"可接线 ≠ 已接线"）、§51.3（缺入口点 ⇒ 调用点无法接线）、
> §52.3（假绿陷阱）、§58.5（战略裁定）、§59.7（默认路径被搬空的真实回归）；车道 `p14-logingate-wire`
> 的 opt-in 做法；各车道 `docs/并行报告-*.md`。
>
> **数据来源**：① 代码机械扫描（命令见 §1.2，全部可复跑）；② 各车道并行报告里的接线对照表；
> ③ 本车道对 `src/GXX.M2Server/Program.cs` 的逐行核对。**凡不确定的写"未给出/未裁定"，不猜。**

## §0 三个必须记住的结论

1. **全工程产品代码里，"宿主 → 接缝"的赋值 = 0 个。**
   `src/GXX.M2Server` 内**没有任何** HostWire / CompositionRoot；唯一的"赋值"是
   ① 各文件自己的 `ResetDefaults()`，② **5 组转发属性**（把接缝 A 的 setter 转写给接缝 B）。
   ⇒ **所有接缝的行为 = 其默认值**（`tests/**` 里有 ~765 处注入，但**测试注入不算接线**）。
2. **"忘记注入"的后果绝大多数是 `静默`（≈ 三分之二）。** 而**静默的一类才是最危险的**
   —— 本工程已登记的「静默中性值 / 静默空实现」事故全都是这一类。本表**逐条分类**，见 §0.2。
3. **`M2EngineService`（M2Server 宿主入口）在本车道之前从未被执行过一次。**
   取证：`M2EngineService` 在 `tests/**` 的修前命中数 = **0**。第一次把它跑起来
   （本车道 `HostWireE2ETests`）就抓到一个**真 bug**（D-P17-01，见 §2）。

### §0.1 后果分类的三档（本表每行必属其一）

| 档 | 名称 | 判据 | 危险度 | 例 |
|---|---|---|---|---|
| **a** | **静默错误** | 无异常、无日志、无计数；只是"行为不对/什么都没做"。含 `?.Invoke` 空转、`= _ => null`、`= _ => 0`、`= (_,_) => { }`、以及**恒真/恒假的开关** | **★★★ 最高** | `PlayerSurfaceSocketSeams.SendSocket = (_,_,_) => { }` ⇒ **所有下发出包静默丢弃** |
| **b** | **显式抛** | 未接线时立刻抛（`NotSupportedException` / `InvalidOperationException` / NRE），当场暴露 | ★ | `NpcSeams.GetCastleUnderWar = _ => throw NotSupportedException(...)` |
| **c** | **可见占位** | 有可观测痕迹：日志、计数器、明显的假值；或**默认值就等价于原文某个已定义状态**（见 §0.3） | ☆ 最轻 | `SweepSeam.MainOutMessage = msg => LoggedMessages.Add(msg)` |

### §0.2 「忠诚表达」不算静默错误（可复用判据，出自 `p4-m2-objnpc` §22.4）

> **能把默认值对应到原文某个已定义状态（如未初始化全局 = `nil`）就是忠实；对应不到就必须抛。**

- 例：`NpcSeams.IsFunctionNpc = _ => false` —— 原文 `Self = g_FunctionNPC`，而该全局
  **在初始化前本来就是 nil** ⇒ 恒 `false` 是**忠实表达**，**不是**静默中性值。
- 反例：D37 `GetCastleUnderWar` —— "真值不可知"（字段存不存在都不确定）⇒ **必须抛**。
- 本表对这类标 **c（忠实）**，并在"后果"列注明。

### §0.3 一条必读的链式陷阱

`NpcSeams.IsUseItem`（`Npc/ObjNpcSeams.cs:621`）的**默认实现**会调用
`GetStdItem(nIndex).Value`。而 `GetStdItem` 的默认是 `_ => null` ⇒ **`.Value` 抛
`InvalidOperationException`**。⇒ 这一条**不是静默**，但根因是上游接缝的静默默认值。
**登记为"跨接缝链式后果"，接线时必须成对处理。**
